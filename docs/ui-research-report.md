# 网易云 / Bilibili / 番剧类第三方客户端 交互与界面设计调研报告

> 调研对象：[YesPlayMusic](https://github.com/qier222/YesPlayMusic)（网易云）· [VutronMusic](https://github.com/stark81/VutronMusic)（网易云）· [BiliPai](https://github.com/jay3-yy/BiliPai)（B 站）· [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)（B 站）· [Kazumi](https://github.com/Predidit/Kazumi)（番剧）。BiliPai 的 [UI 设计规范](https://github.com/jay3-yy/BiliPai/blob/main/docs/wiki/ui-design/README.md) 是完整的一手设计系统文档，本报告大量提炼自它。

## 一、各项目交互设计要点

### 1. YesPlayMusic（网易云第三方播放器，~30k star）

- **核心布局**：经典三区式 —— 左侧边栏（顶部常驻搜索框 + 导航「发现 / 音乐库」+ 下方收藏歌单列表）、右侧主内容区、底部全局通栏播放器。音乐是"全局持续状态"，播放器永不因翻页而中断。
- **首页信息架构**：推荐歌单 + 新歌/新碟 + 每日推荐 + 私人 FM 并列入口，内容卡片网格（正方形封面 + 歌单名 + 播放量）。首页是"发现"，音乐库是"我收藏的"。
- **关键交互**：
  - **播放页/歌词**：全屏歌词视图，背景用封面取色做模糊/渐变，支持逐句翻译与罗马音；歌词可点跳转。
  - **搜索**：侧边栏顶部常驻，输入即联想，回车进搜索结果页（歌曲/歌单/专辑分 Tab）。
  - **登录**：扫码 / 手机 / 邮箱三种入口，未登录也能浏览。
- **空态/加载态**：依赖 Vue 生态的加载骨架；变灰歌曲（版权下架）自动用 [UnblockNeteaseMusic](https://github.com/UnblockNeteaseMusic/server) 替换音源，把"不可用"变成"可用"而非报错。
- **反馈与视觉**：红粉品牌色，Light/Dark 自动切换，封面取色做氛围渐变；支持 PWA、Touch Bar、全局快捷键、Mpris 系统媒体控制——把"系统级无缝"当成体验的一部分。

### 2. VutronMusic（stark81/VutronMusic，高颜值多数据源桌面播放器）

- **核心布局**：侧边导航栏 + 分区内容，界面和功能大量参考 YesPlayMusic，侧栏导航设计参考"方格音乐"，本地音乐页顶部统计参考 NSMusicS。截图分区：首页 / 发现(Explore) / 音乐库(Library) / 我喜欢 / 本地音乐 / 歌单 / 播放页 / 评论页 / 搜索+歌词 / 音效 / 用户 / MV。
- **关键特点**：
  - **插件化多数据源**：网易云、酷狗、本地、流媒体(navidrome/jellyfin/emby) 统一到一个播放器里——和本项目"三模块统一壳子"是同构需求，值得直接对标。
  - **逐字歌词**：歌词逐字高亮 + 桌面歌词（Mac 状态栏 / Touch Bar / GNOME / KDE 顶栏），把"歌词"做成多形态的外显能力。
  - **变调变速、音效、云盘、评论**：在播放页做高级音频控制，但都收进次级面板，不干扰主播放。
- **反馈**：播放页与列表页分离，全屏播放页是独立"页"，而非悬浮层。

### 3. BiliPai（jay3-yy/BiliPai，原生纯净可扩展的 B 站 Android 客户端）

最有参考价值的是它**把交互设计写成了工程规范**（`docs/wiki/ui-design/`，含 12 个分册 + 10 类页面母版 + 61 个导航 Key + 12 种状态合同）。要点：

- **核心布局**：`AppScaffold` 统一外壳 —— Compact 用底部导航，Medium/Expanded 用 NavigationRail/Sidebar；主导航、系统栏 inset、迷你播放器、内容都由外壳唯一拥有，首页只是其中一个"目的地"。
- **三风格设计系统**：Miuix（默认完整验收）+ iOS + Material 3 三套皮肤共享同一套"语义合同"（功能、信息、状态、导航、无障碍、品牌一致，只有外观可不同）——业务层只写 `AppButton(onClick=...)`，不直接碰底层组件。
- **基础 Token**：间距 2/4/8/12/16/24/32/48dp；圆角按语义分级（Tag 4 / Chip 6 / Field 10 / Card 12 / Dialog 14 / Sheet 20 / Floating 28）；点击热区 ≥48dp；颜色按"角色"而非十六进制；图标同语义同家族。
- **12 种页面状态合同**（金标准）：首次加载、刷新、正常、部分数据、空内容、失败、离线、未登录、权限不足、禁用、分页加载、分页结束 —— 每页必须逐一回答，例如"空内容=是没有数据还是筛选无结果""未登录不伪装成网络错误"。
- **搜索**：搜索框保持焦点，输入防抖+取消旧请求；无查询时显示历史/建议/热榜；结果按类型 Tab；返回先关建议/收键盘/清焦点再回来源，详情返回恢复查询与位置。
- **播放器**：DASH/4K/HDR、弹幕、手势、后台播放、画中画、听视频；媒体区固定宽高比，加载/缓冲/失败三态可区分；全屏/PiP/返回所有权明确。
- **动效**：动效从 `AppMotionTokens` 取参数，禁止业务代码硬编码 tween/spring；玻璃/模糊只用于导航栏/控制层/悬浮层且必须有降级；"减少动态效果"下关闭脉冲/粒子/大幅缩放。
- **自适应**：断点 360 / 700 / 840 / 1000 / 1600dp，宽屏把"次要内容"移到右侧但**不改变阅读顺序**，长文本限制最大宽度，封面增列不拉伸。

### 4. PiliPlus（bggRGjQaUbCoE/PiliPlus，Flutter 版 B 站第三方）

- **核心布局**：完整 B 站信息架构（首页推荐 / 最热 / 热门直播 / 番剧列表 / 动态 / 私信 / 个人），首页为推荐流。
- **播放器交互（成熟手势体系）**：双击快进/快退、双击暂停、**垂直滑动调亮度/音量、上滑进全屏、下滑退全屏、水平滑动快进/快退**、倍速 + 长按 2 倍速、画质/音质/解码选择、记忆播放、高能进度条、滑动跳转预览视频缩略图、SponsorBlock、超分辨率。
- **搜索**：热搜、搜索历史、默认搜索词、投稿/番剧/直播间/用户分类搜索、排序与时长筛选。
- **反馈与趣味动效**：**三连动画、投币动画**（轻互动即时反馈）、评论楼中楼、富文本/表情/@ 动态。
- **设置**：画质/音质/解码预设、图片质量、主题（亮/暗/跟随系统）、震动反馈可选、高帧率、自动全屏。

### 5. Kazumi（Predidit/Kazumi，Flutter 番剧聚合工具）

- **核心布局**（从 `menu.dart` 实测）：Material `NavigationBar` 底部 4 Tab —— **推荐 / 时间表 / 追番 / 我的**，宽屏切换为 `NavigationRail` 并额外暴露**搜索**入口。首页(推荐)=番剧目录，时间表=按星期排列的更新日历。
- **关键交互**：
  - **规则引擎**：5 行 Xpath 自定义采集规则 + 规则导入/分享 + 规则编辑器/管理页，把"内容来源"做成用户可扩展的能力（与本项目"服务列表启动器"同构）。
  - **首次引导**：有 `onboarding`（引导）+ `init_page`（初始化配置）两个首启页面 —— 先引导再配置，避免空壳。
  - **播放**：分集、多视频源、字幕、弹幕、倍速、硬件加速、高刷、Anime4K 超分辨率、外部播放器、DLNA、一起看、下载。
  - **个性化**：追番列表、历史记录、配色方案、跨设备同步。

## 二、通用设计模式总结（重点）

### 1. 信息架构与导航（如何让用户不迷路）
- **双层导航是共识**：① 顶部一层"主目的地"（首页/搜索/我的）用 **Tab 常驻切换、不压栈**；② 只有详情/播放这类"深入一层的对象"才压栈。BiliPai 明确"底栏只切换主目的地，不重复 push"；YesPlayMusic 用侧边栏承载主目的地，播放器全局悬浮。
- **外壳与内容所有权分离**：全局导航、系统栏、迷你播放器由外壳唯一拥有，首页只是其中一个目的地（BiliPai P001）。这样切 Tab 不会重建播放器。
- **重复点击当前 Tab = 回顶，不重复压栈**。
- **宽屏用 Rail/Sidebar，窄屏用底栏**，两者是同一语义的两种形态（Kazumi、BiliPai 都这么做），且"底栏与 Rail 不同时暴露"。

### 2. 首页内容组织（如何展示推荐/热门/历史）
- **内容优先，不做大 Hero 营销位**：BiliPai 明确"顶部工具和推荐卡不做营销式大 Hero，也不把普通区块全部做成浮动卡"。
- 首页结构 = **顶部搜索/身份 + 分类 Tab + 横向重点内容(可选) + 推荐列表/网格 + 刷新与分页状态**。
- **个性化入口前置**：每日推荐/私人 FM/最近播放/追番更新/历史——个人场景下"继续上次"比"海量推荐"更重要。

### 3. 播放器/观看器的交互
- **播放器是全局持续状态**：迷你播放器悬浮在底栏之上，跨页面/跨模块不断播，点击展开全屏（YesPlayMusic/VutronMusic）。
- **手势标准化**（PiliPlus）：双击暂停/快进快退、垂直调亮度音量、上下滑进出全屏、水平快进、倍速+长按 2 倍、记忆播放。
- **媒体区固定宽高比**，控制层不遮挡关键信息，**加载/缓冲/失败三态可区分**（BiliPai T09）。
- **高级控制收进次级面板**（倍速/画质/音效/字幕），不污染主界面。

### 4. 空状态与引导（首次使用、无数据时）
- **空态与错误态组件化**：`AppEmptyState`（图标+标题+解释+可选动作）与 `AppErrorState`（图标+标题+原因+重试/返回）——文案铁律：空态说"**没有什么 + 可做什么**"，错误说"**发生什么 + 下一步**"。
- **区分三种"空"**：真的没数据 / 筛选无结果 / 首次加载未完成（未完成不能提前显示空）。
- **未登录 ≠ 网络错误**：不伪装、不强制弹登录，给"去登录/去配置"入口。
- **首次引导**：Kazumi 用 onboarding(引导) + init_page(初始化配置) 两页，先讲"这是什么、怎么配"，再让用户配置——自托管项目必须走这一步。
- **空态不用巨型插画占满宽屏**。

### 5. 搜索交互
- **搜索框常驻 + 焦点分级**：无查询时显示历史/建议/热榜，提交后显示结果；**清空只清查询不离开页面**。
- **防抖 + 取消旧请求**：输入即联想、旧请求作废（BiliPai/YesPlayMusic）。
- **结果按类型 Tab**（歌曲/歌单/视频/番剧/用户），宽屏把筛选与结果并排。
- **返回优先级**：先关建议 → 清焦点收键盘 → 再返回来源；详情返回要恢复查询、类型、筛选和滚动位置。
- **历史支持单项删除/清空，热词可点击直接提交**（PiliPlus 热搜+历史+默认词）。

### 6. 反馈与状态（加载、成功、失败、进度）
- **反馈组件分层**（BiliPai C401–C406，可直接套用）：
  - `Dialog` 只用于风险确认/阻塞错误/少量关键选择，**普通成功不弹窗**；
  - `Snackbar/Toast` 用于非阻塞短结果 + 一个可选撤销动作（如"已从稍后再看移除 [撤销]"）；
  - `BottomSheet` 用于筛选/选择/补充内容；
  - `DropdownMenu` 用于低频操作，高频模式选择直接可见。
- **加载态 = 与真实卡同尺寸的骨架/稳定占位**，刷新保留旧内容 + 顶部细进度条，分页用尾部轻量 spinner，到底显示"已经到底啦"（避免无限请求）。
- **轻互动即时动效**：三连动画、投币动画、点赞/追番动效，可被"减少动态效果"关闭。
- **状态播报克制**：错误播报一次、空态不重复播报、live region 不频繁打断。

### 7. 视觉语言（色彩、圆角、层级、动效）
- **Token 化一切数值**：间距 4/8/12/16/24/32；圆角按语义分级（Tag 4 / Chip 6 / Field 10 / Card 12 / Dialog 14 / Sheet 20 / Floating 28）；点击热区 48dp。
- **颜色按角色不按十六进制**：背景/表面/次级表面/主操作/错误/边框/文字，浅色+深色(含 AMOLED)都要过；**错误色只表达破坏性语义**，品牌粉不能当危险色。
- **封面取色做氛围**（YesPlayMusic 歌词页背景渐变）。
- **层级靠留白/边框/层级，不只靠阴影**；玻璃/模糊只用于导航栏/迷你播放器/控制层，必须有无模糊降级。
- **动效服务层级反馈**，不装饰；统一时长/缓动 Token，进入/退出/连续移动用匹配 easing 与方向；禁用无理由硬编码 tween/spring；"减少动效"下只保留短淡入。

### 8. 响应式与移动端适配
- **断点分级**：360(单栏+底栏) / ~700(双列+Rail) / 840(列表-详情双栏) / 1600(媒体专用)，同页信息顺序不变。
- **宽屏增列不拉伸**：封面按列数增加而非无限放大；长文本限最大阅读宽度。
- **固定格式元素用 aspectRatio/grid track/min-max** 约束，加载文字不撑动布局。
- **列表用稳定 key**：刷新、分页、占位不使已显示项目跳动。
- **双栏详情关闭 = 回列表选中态，不是退出功能**。

## 三、对本项目（自托管个人媒体中心 Web 应用，网易云/B站/番剧三模块）的具体改造建议

> 现状：三模块装在统一壳子里（服务列表启动器 → 进模块），模块内是「返回按钮 + 页面栈」导航，卡片网格展示内容。以下建议按优先级排序。

### 🔴 高优先级（决定整体结构与体验下限）

1. **把"服务列表启动器"升级为常驻侧边栏/Rail**：三模块（音乐/B站/番剧）+ 搜索 + 设置平级常驻，模块间一键切换、状态互不销毁，不再"启动器→进模块→返回"。窄屏折叠为底部 Tab 或抽屉。
2. **模块内改双层导航**：主目的地（首页/搜索/我的）用 Tab 常驻切换不压栈；只有详情/播放器压栈。消灭"一路返回才能换页"。
3. **全局唯一迷你播放器**：音乐与视频共用一个底部迷你播放器，悬浮在导航之上，跨模块不断播，点击展开全屏播放页（对标 YesPlayMusic/VutronMusic）。
4. **先建设计 Token**：间距(4/8/12/16/24/32)、圆角分级(Tag4/Chip6/Field10/Card12/Dialog14/Sheet20/Floating28)、点击热区≥48px、颜色按"角色"定义（含深色/AMOLED）。
5. **统一 12 种页面状态组件**：首次加载/刷新/正常/部分/空/失败/离线/未登录/权限/禁用/分页加载/分页结束，三模块所有列表复用同一套占位/空态/错误组件。
6. **卡片网格统一规格**：固定封面宽高比（视频 16:9、音乐 1:1、番剧海报 2:3）、标题最多 2 行截断、作者/统计一行小字，用骨架屏占位避免跳动。
7. **搜索框常驻 + 焦点分级**：无输入显示"历史 + 热搜词"，输入即联想，提交后结果按类型 Tab（歌曲/歌单/视频/番剧/用户），清空只清词不离页。
8. **首次引导 onboarding**：首次打开/首次配模块时，3–4 屏讲"这是什么 → 怎么配服务 → 快速开始"，再接初始化配置页（对标 Kazumi 的 onboarding + init_page）。
9. **未登录/未配置不伪装成"网络错误"**：单独给"去配置 / 去登录"入口，可浏览公开内容。
10. **统一反馈组件**：Snackbar/Toast(非阻塞短结果+可选撤销) + Dialog(仅风险确认) + BottomSheet(筛选/选择) + 下拉菜单(低频操作)，三模块共用。

### 🟡 中优先级（体验细节，明显提质感）

11. **首页内容组织**：顶部搜索/身份 + 分类 Tab + 推荐/热门流 + 下拉刷新；不做大 Hero；三模块各自前置"最近播放/继续观看/追番更新/历史"。
12. **下拉刷新保留旧内容 + 顶部细进度条**；分页用尾部轻量 spinner；到底显示"已经到底啦"。
13. **空状态区分语义**：真没数据 vs 筛选无结果 vs 加载未完成，文案"没有什么 + 可做什么"，不用巨型插画。
14. **轻互动即时动效**：点赞/追番/收藏加一次性轻动效（对标 PiliPlus 三连/投币动画），可被"减少动效"开关关闭。
15. **搜索防抖(约 300ms) + 取消旧请求**，返回先关建议/收键盘再回来源，详情返回恢复查询与滚动位置。
16. **搜索历史**支持单项删除/清空，热词点击直接提交。
17. **播放器手势**：双击暂停/快进快退、垂直调亮度音量、上滑进全屏/下滑退出、水平快进、倍速+长按 2 倍、记忆播放（对标 PiliPlus）。
18. **高级控制收进次级面板**：倍速/画质/音效/字幕收进底部面板或菜单，不污染主界面。
19. **主题明暗双模式 + 跟随系统**：音乐用专辑封面取色渐变，B站品牌粉、番剧海报色，但错误色始终独立。
20. **断点分级响应式**：360(单栏+底栏) / ~700(双列+Rail) / 840(列表-详情双栏) / 1600(媒体专用)，信息顺序不变。
21. **列表用稳定 key**：刷新/分页不跳动已显示项目；固定尺寸用 aspectRatio 约束。
22. **图标与文案统一**：图标同语义同家族；文案规范——结果型("已添加到歌单")、按钮动词、空态"没什么+可做啥"、错误"发生啥+下一步"。

### 🟢 低优先级（打磨与无障碍）

23. **玻璃/模糊只用于导航栏/迷你播放器/控制层**，且必须有无模糊降级（性能敏感）。
24. **动效统一 Token**：时长/缓动从设计系统取，禁止业务硬编码 tween/spring，进入/退出方向一致。
25. **宽屏限制正文最大阅读宽度**，封面增列不拉伸。
26. **键盘/无障碍**：错误播报一次、装饰图标 aria 空、可点击图标给动作名、Tab 交互区≥48px。
27. **返回语义一致**：系统返回/顶部返回/预测返回结果相同；宽屏双栏关闭详情=回列表选中态而非退出模块。
28. **离线能力**：保留缓存并显式标明"离线/受限"，不伪装成功。
29. **变灰歌曲/失效源降级**：仿 YesPlayMusic 自动换源，或明确"不可用+可替换"而非纯报错。
30. **插件/规则扩展入口**：仿 VutronMusic(数据源插件)、Kazumi(Xpath 规则)、BiliPai(JSON 插件)，把"内容来源"做成可扩展能力，降低自托管维护成本。

**核心结论**：这些高分项目的一致性规律是——**「外壳唯一 + 双层导航 + 全局迷你播放器 + Token 化设计系统 + 12 状态合同 + 组件化空态/反馈 + 首次引导」**。对本项目而言，最高杠杆的三件事是：① 把启动器改成常驻侧边栏；② 建一套 Token + 12 状态组件；③ 加全局迷你播放器和首次引导。其余细节都可在此基础上逐步对齐。
