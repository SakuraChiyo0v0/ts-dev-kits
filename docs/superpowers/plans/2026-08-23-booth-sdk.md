# `@sakurachiyo0v0/booth` Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. 设计文档:`docs/superpowers/specs/2026-08-23-booth-sdk-design.md`。

**Goal:** 在 `ts-dev-kits` monorepo 中交付可复用的 `@sakurachiyo0v0/booth` SDK:BOOTH(booth.pm)登录态管理、商品解析、免费领取/付费下单、订单文件下载与批量编排,配套 `sc-booth` CLI 与 `skills/booth-cli/SKILL.md`。

**Architecture:** 与 `@sakurachiyo0v0/netease-music` 同构:统一 `BoothClient` 入口,登录态复用 `@sakurachiyo0v0/account` 的 `AuthStore`(cookie 字符串凭证),请求层用 Node 原生 fetch(undici),单测走本地 mock HTTP 服务器(`baseUrl`/`fetchImpl` 注入)。CLI 用 `@sakurachiyo0v0/cli-utils` 的参数解析/输出/错误处理。

**Tech Stack:** TypeScript 7、Node.js 20+、pnpm 11、Vitest 4、Rollup 4;运行时零第三方依赖(fetch 用原生 undici,临时登录服务用 `node:http`)。

## Global Constraints

- 包名 `@sakurachiyo0v0/booth`,`UNLICENSED`,私有,不发布公共 registry;依赖 `@sakurachiyo0v0/account`(workspace:*)与 `@sakurachiyo0v0/cli-utils`(workspace:*)。
- SDK 只运行于可信服务端进程(Node 20+);cookie/会话内容不得进日志或错误消息(脱敏)。
- 付费商品只生成待支付订单,SDK 不做任何支付操作;不绕过支付、不伪装会员、不代抢。
- 批量领取默认并发 1(可配置),避免站方压力;不鼓励囤积转售。
- 无官方公开 API,端点来自逆向;所有端点 URL 集中常量化(`src/api/endpoints.ts`),页面结构解析失败报 `API_ERROR` 提示更新 SDK。
- 真实冒烟仅领取用户明确同意、指定链接的免费商品;不进 CI。
- 提交/推送/发布分别需用户授权;计划内不自动执行 git commit / push。

## Task 3: 下单与订单状态

**Files:**
- Create: `packages/booth/src/api/order.ts`
- Extend: `tests/helpers/mock-server.ts`(下单 + 订单状态端点)
- Create: `packages/booth/tests/order.test.ts`

**Interfaces:** `OrderApi.create(item: BoothItem): Promise<ClaimResult>`;`OrderApi.isPaid(orderId): Promise<boolean>`。

- [ ] **Step 3.1: order.ts**

`create(item)`:带会话 cookie + CSRF token POST 下单端点;按响应分派:
- 0 日元成交 → `{ status: "claimed", orderId }`;
- 付费待支付 → `{ status: "paid-pending", orderId, payUrl }`(payUrl 从响应/重定向提取);
- 已拥有 → `{ status: "skipped" }`;
- 未登录 → `LOGIN_REQUIRED`;响应异常 → `API_ERROR`。
`isPaid(orderId)`:查订单状态端点 → boolean。

- [ ] **Step 3.2: mock-server 扩展**

`POST` 下单端点按 body(item id / csrf)与 fixture 返回成交/待支付/已拥有/未登录;订单状态端点返回 paid/unpaid。

- [ ] **Step 3.3: 测试**

免费下单 → claimed;付费 → paid-pending 含 payUrl;已拥有 → skipped;未登录 → LOGIN_REQUIRED;isPaid 两态。
